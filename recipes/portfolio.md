# Recipe: portfolio

Small component set, high design ambition. The type and the images do the work.

## Components you'll probably need
Navigation · Hero · ProjectCard · MediaSection · FeatureGrid · Footer

## Pull from DemoDesignSystem
Nearly everything — this is exactly what that repo is. `Hero`, `ProjectCard`,
`About`, `Skills`, `SkillItem`, `Navigation`, `Menu`, `Logo`, `Footer`.

## Set up in Figma first
- Decide image aspect ratios as a fixed set and treat them as a design
  decision. Portfolios die from inconsistent crops.
- A display type style that is genuinely large at `lg` and still works at `sm`.

## Watch out for
- This is the type most likely to want one bespoke, non-systematic page. Let
  it — but keep it in its own file and do not bend the design system to fit it.
- Image weight. A portfolio is mostly photographs; export properly and use
  modern formats.
